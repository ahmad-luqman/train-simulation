# Save migration fixtures

The `release-v5` through `release-v8` gzip files are frozen JSON saves generated by executing the corresponding historical commit's **own** `Simulation`, advancing 400 fixed 50 ms ticks, then serializing `save()` without editing its schema:

| Format | Source commit |
| ------ | ------------- |
| v5     | `d977c6e`     |
| v6     | `efb7de3`     |
| v7     | `be27a7d`     |
| v8     | `bb7d9d6`     |

The release storage regression restores each actual historical format, preserves its network, cash and every train's physical authority/position, advances it, then saves and restores through the new library. Keep these fixtures unchanged when extending the format. The earlier `phase3-*` files remain separate collision-audit evidence.
